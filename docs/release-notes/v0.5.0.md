## wt-monitor v0.5.0 — "waiting for you" alerts, external notifications and Alexa

### Added
- **"Waiting for you" notifications.** When an agent asks you a question or waits on a permission prompt and you don't answer within a few seconds, you get an urgent desktop notification. The agent hook now also runs on Claude Code's `Notification` and `PreToolUse` (`AskUserQuestion`) events and never delays the agent. Run `make hooks` again to add them.
- **External notifications (opt-in, `WT_NOTIFY_CMD`).** Any notification can also run a command of your choice, with the event as environment variables and JSON. `WT_NOTIFY_EVENTS` picks which events (`ask`, `done`, `cpu`, `wait`, `mem`, `sysmem`). Off by default: without it, wt-monitor still makes no network requests.
- **Home Assistant and Alexa** (`contrib/home-assistant`). A step-by-step guide, a webhook script and automations so an Echo announces when an agent needs you, and so you can ask *"Alexa, status dos agentes"* or *"Alexa, quem precisa de mim"*. The guide explains what goes through Amazon's cloud and how to protect the stored Amazon session.
- `GET /api/attention`: read-only summary of open agents, busy agents and pending questions.
- **Terminals without an active worktree.** The Terminals tab always offers the watched root, so you can open a shell or Claude before any worktree exists.

### Fixed
- An intermittent JavaScript error when closing a terminal right after it was drawn.
- CI is green again.

Upgrade: `git pull && make hooks && make install`. Full list in the [CHANGELOG](https://github.com/patrezelopes/wt-monitor/blob/main/CHANGELOG.md).
