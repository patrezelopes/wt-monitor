## wt-monitor v0.3.1 — build fix and clearer docs

A small patch release. **No change to the dashboard itself**: the binary behaves like v0.3.0.

### Fixed
- `make` now finds `cargo` in `~/.cargo/bin`. Before, shells where rustup's directory was not on `PATH` failed with `cargo: not found` (for example `make install TERMINALS=1` run from a non-login shell).

### Documentation
- New README section **"How is this different?"**: wt-monitor is a lightweight observer of the agents you already run, next to workspace and orchestrator tools such as Orca and Compozy, and it says what it deliberately does not try to be.
- The README now covers the `--print-token` command, the `WT_TERMINALS` and `WT_TOKEN_FILE` settings, the `mode=term` and `layout` URL parameters, and links to the changelog and the third-party notices.

Upgrade: `git pull && make install` (add `TERMINALS=1` to keep terminals enabled). Full list in the [CHANGELOG](https://github.com/patrezelopes/wt-monitor/blob/main/CHANGELOG.md).
