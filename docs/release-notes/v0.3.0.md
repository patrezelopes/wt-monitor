## wt-monitor v0.3.0 — terminals inside the dashboard

**Run real terminals — a login shell or `claude` — in your worktrees without leaving the dashboard.** Opt-in, started by the panel, protected by a token.

### What's new
- 🖥 **Terminals started by the panel** — a new *Terminals* view runs a login shell (or `claude` in one) in any worktree, rendered with [xterm.js](https://xtermjs.org/).
- 🗂 **Sets of terminals** — tabs grouped by worktree, and a `1 / 2 / 4` switch to show that many side by side.
- 🔁 **They survive reloads** — terminals live in the server; reconnecting replays the last 256 KB of output. Ended terminals stay listed for 10 minutes with their exit code. Up to 16 at once.
- ⚡ **One click from a session** — the session drawer has *Terminal* and *Claude* buttons for that worktree.
- 🔐 **Secure by design** — off by default, authorised by a `0600` token file that no API ever returns, `Origin`/`Host` checks, and a closed set of commands. Read [SECURITY.md](https://github.com/patrezelopes/wt-monitor/blob/main/SECURITY.md).
- 🧪 **`make e2e`** — end-to-end tests over HTTP/WebSocket and in a real headless Chrome (CI runs them).
- Still **zero Rust dependencies**: the PTY uses the libc that `std` links, and the WebSocket is implemented in-tree against the RFC 6455 vectors. xterm.js 5.5.0 (MIT) is embedded; the UI makes no network requests.

![terminals](https://raw.githubusercontent.com/patrezelopes/wt-monitor/v0.3.0/docs/img/terminals.png)

### Enable it
```bash
make install TERMINALS=1     # or: make run TERMINALS=1   /   wt-monitor --terminals
make open-terminals          # opens the dashboard with the one-time token in the link
```
Without `--terminals` nothing changes: every terminal route answers 404.

### Good to know
Terminals run your login shell as your user, so anyone who holds the token can run commands as you: treat `~/.config/wt-monitor/token` like an SSH key. Only terminals started by the panel are managed; it never attaches to terminals you opened elsewhere. Linux only. Full list of changes in the [CHANGELOG](https://github.com/patrezelopes/wt-monitor/blob/main/CHANGELOG.md).

### 🇧🇷 Em português
- **Terminais iniciados pelo painel** (shell de login ou `claude`) em qualquer worktree, com xterm.js — **opt-in**.
- **Conjuntos de terminais**: abas por worktree e `1 / 2 / 4` lado a lado; sobrevivem a recarregar a página (a saída é reenviada); até 16 ao mesmo tempo.
- Botões **Terminal** e **Claude** na gaveta da sessão.
- **Seguro por padrão**: desligado, token num arquivo `0600` que nenhuma API devolve, verificação de `Origin`/`Host` e conjunto fechado de comandos (veja o [SECURITY.md](https://github.com/patrezelopes/wt-monitor/blob/main/SECURITY.md)).
- Continua **sem dependências Rust**.

Para habilitar: `make install TERMINALS=1` e depois `make open-terminals`.
