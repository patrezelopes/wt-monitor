## wt-monitor v0.2.0 — agents, skills and a new look

**See what your AI agents are doing in every worktree, not just how much CPU they use.**

### What's new
- 🤖 **Agents & sub-agents** — the main agent plus every running sub-agent (type, model, current tool).
- 🧩 **Skills** — which skill a session is using.
- 💬 **Who talks to whom** — delegations, `SendMessage` and completions between agents, drawn as a topology with message packets.
- 🚦 **Status per worktree** — working, waiting for you, idle or at the limit.
- 🗂 **Session drawer** — overview, agents, live activity and processes tabs.
- 🎨 **A redesigned UI** — dense table *Overview* (dark and light) and a refined *Arena* with sub-agents wired to the main agent.
- 🔎 Branch per worktree, status filters, and search by worktree, branch, agent or skill (`Ctrl K`).
- 🛠 `Makefile` for everything (`make help`), plus `make hooks-uninstall` and CI.

### Upgrade
```bash
git pull && make install     # rebuilds and restarts the user service
make hooks                   # optional: "task finished" notifications
```
Try it without any setup: open the dashboard with `?demo` (e.g. `http://127.0.0.1:8765/?demo&mode=fun`).

### Good to know
Agent, skill and *waiting for you* detection is inferred from Claude Code transcript files — a format that is not a stable API — so it is best-effort. Linux only. Full list of changes in the [CHANGELOG](https://github.com/patrezelopes/wt-monitor/blob/main/CHANGELOG.md).
